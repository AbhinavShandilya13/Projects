# Projects Repository
Welcome to my repository. This is a collection of various projects I have worked on to practice and demonstrate my skills in data analysis, visualization, and machine learning. Each folder contains a unique project with its own set of data, code, and objectives.

## 📂 Projects Overview
### 1. Retail Bank Customer Churn Analysis
- Description: An analysis of bank customer data to identify key factors leading to churn and visualize the findings.

- Highlights:

  - Created an interactive dashboard in Power BI to explore churn drivers.

  - Identified at-risk customer segments based on geography and activity level.

- Tech Stack: Power BI, Excel


### 2. Bikeshop Sales Analysis
- Description: A business intelligence project analyzing sales data to find patterns and insights for a local bikeshop.

- Highlights:

  - Analyzed customer demographics and product performance.

  - Identified the most profitable customer segments to inform marketing strategy.

- Tech Stack: Excel, Power BI



### 3. COVID-19 Data Exploration & Visualization
- Description: A data-focused project to clean, explore, and visualize global COVID-19 data.

- Highlights:

  - Used SQL and Python for complex data querying and manipulation.

  - Created Tableau visualizations to show the relationship between vaccinations and mortality rates.

- Tech Stack: SQL, Tableau, Python, Pandas



### 4. Airbnb Listings Analysis
- Description: An analysis of Airbnb listing data to understand pricing, availability, and geographic trends in the market.

- Highlights:

  - Explored pricing strategies and seasonal demand patterns.

  - Visualized the geographical distribution of listings using Tableau.

- Tech Stack: Tableau



### 5. Speech Emotion Recognition
- Description: A machine learning project that classifies emotions from speech data.

- Highlights:

  - Performed feature extraction from raw audio files.

  - Built and trained a model to identify emotional tones in speech.

- Tech Stack: Python, Scikit-learn

### 6. Handwritten Digit Recognition
- Description: A deep learning project using a Convolutional Neural Network (CNN) to recognize handwritten digits.

- Highlights:

  - Preprocessed image data from the MNIST dataset for optimal training.

  - Achieved high accuracy with a well-designed CNN architecture.

Tech Stack: Python, TensorFlow
